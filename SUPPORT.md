# Support

- Read the [user guide](docs/USER_GUIDE_RU.md) and [FAQ](docs/FAQ_RU.md).
- Search existing GitHub issues before opening a new one.
- Use the bug template and remove tokens, phone numbers, session strings, API hashes and private chat content from logs.
- Security issues belong in private vulnerability reporting, not public issues.

The project is community maintained; response times are not guaranteed.
