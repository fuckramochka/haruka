# Руководство пользователя Haruka

## 1. Что это

Haruka работает от лица твоего Telegram-аккаунта и превращает команды в действия. Это не официальный клиент Telegram. Использование автоматизации может ограничиваться правилами Telegram; владелец аккаунта сам отвечает за сценарии и установленные расширения.

## 2. Установка

### Linux/macOS

```bash
git clone https://github.com/fuxckramochka/haruka.git
cd haruka
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[full]'
cp .env.example .env
python -m haruka
```

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---:|---|
| `API_ID` | да* | ID приложения Telegram |
| `API_HASH` | да* | Hash приложения Telegram |
| `HARUKA_SESSION` | нет | имя файла сессии |
| `HARUKA_DATA_DIR` | нет | каталог БД, сессии и расширений |
| `AI_API_KEY` | нет | ключ OpenAI-совместимого провайдера |
| `AI_BASE_URL` | нет | адрес совместимого API |
| `AI_MODEL` | нет | модель по умолчанию |

`*` Если значений нет, терминал спросит их при первом запуске.

## 3. Первые команды

| Команда | Что делает |
|---|---|
| `.help` | открывает Command Atlas |
| `.help -c` | показывает встроенные возможности |
| `.help -l` | показывает сторонние расширения |
| `.info` | статус Haruka |
| `.health` | диагностика процесса |
| `.menu` | Control Center |
| `.prefix !` | меняет префикс на `!` |
| `.modules` | список загруженных возможностей |
| `.version` | версия и Git revision |

Префикс по умолчанию — точка.

## 4. Control Center

Для панели нужен отдельный бот:

1. Получи токен у `@BotFather`.
2. Отправь `.setbot токен` из своего аккаунта.
3. Перезапусти Haruka командой `.restart`.
4. Открой созданного бота и нажми Start.
5. Выполни `.menu`.

Панель умеет менять визуальный стиль, отключать команды и возможности, показывать роли и состояние процесса. Настройки сохраняются в SQLite и переживают перезапуск.

## 5. Управление расширениями

```text
.loadmod https://example.org/module.py
.multiload URL1 URL2
.unloadmod ModuleName
.multiunload ModuleOne ModuleTwo
.reloadmod ModuleName
.togglemod ModuleName
.togglecmd command
.clearmodule filename.py
```

Перед загрузкой открой исходник и проверь сетевые запросы, работу с файлами, `subprocess`, `eval`, чтение сессий и отправку данных.

## 6. Роли

- **OWNER** — владелец сессии, полный доступ.
- **SUDO** — доверенный пользователь с административными командами.
- **SUPPORT** — ограниченный помощник.
- **EVERYONE** — публичные безопасные обработчики.

Команды управления: `.addsudo`, `.addsupport`, `.revoke`, `.perms`, `.audit`.

## 7. Резервные копии

`.backup пароль` создаёт зашифрованный снимок настроек и отправляет его в Saved Messages. Для восстановления ответь на файл командой `.restore пароль`. Пароль не восстанавливается.

## 8. Обновления

- `.update` выполняет `git pull --ff-only` и перезапуск.
- `.restart` перезапускает процесс без обновления.
- Перед крупным обновлением сделай backup и сохрани копию каталога данных.

## 9. Частые проблемы

- **Control Center не открывается:** сначала напиши `/start` своему companion-боту.
- **Команда молчит:** проверь префикс, `.togglecmd`, `.togglemod` и роль.
- **Расширение не грузится:** проверь Python-синтаксис, публичность URL и лимит 512 KiB.
- **FloodWait:** не повторяй массовые действия; дождись срока Telegram.
- **Сессия потеряна:** проверь `HARUKA_DATA_DIR` и Docker volume.
