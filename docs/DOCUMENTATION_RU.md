# Haruka Userbot — Документация (RU)

Haruka — быстрый модульный Telegram-юзербот, современный форк Heroku/Hikka:
переименован и сильно оптимизирован. Полностью совместим с модулями
(плагинами), при этом заметно быстрее запускается и экономит память.

---

## ✨ Главные возможности

- **Полная поддержка модулей** — установка плагинов одной командой; старые
  плагины Heroku/Hikka продолжают работать благодаря прозрачному
  перенаправлению импортов.
- **Движок `harukatl`** — Telegram-слой доступен как `harukatl`; любой импорт
  `harukatl` / `telethon` / `hikkatl` прозрачно перенаправляется в реальную
  быструю библиотеку.
- **Быстрый запуск** — кэш байткода, `uvloop` и `orjson` делают повторные
  запуски заметно быстрее.
- **Мало памяти** — ограниченный LRU+TTL кэш сущностей и `__slots__`.
- **Inline-режим** — управление через inline-кнопки и формы.
- **Веб-панель** — настройка всего из браузера.
- **Встроенные модули** — инфо о системе, карточка `neofetch`, личный
  блокнот, переводы, терминал, обновления, безопасность и другие.
- **Кросс-платформенность** — Linux, macOS, FreeBSD, Termux (Android), UserLAnd,
  Windows.

## 🚀 Быстрая установка

### Linux / macOS / FreeBSD / Termux / UserLAnd

```sh
git clone https://github.com/coddrago/Heroku Haruka
cd Haruka
chmod +x start.sh
./start.sh
```

### Windows

```bat
git clone https://github.com/coddrago/Heroku Haruka
cd Haruka
start.bat
```

Или через PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

При **первом запуске** автоматически устанавливаются системные зависимости,
создаётся виртуальное окружение (`.venv`) и скачиваются все библиотеки.
Следующие запуски просто стартуют бота.

> Требуется **Python 3.10+**.

## 🔑 Как получить API ID и API HASH

Haruka входит в ваш аккаунт Telegram через официальный API, поэтому нужны
личные **API ID** и **API HASH**:

1. Откройте **https://my.telegram.org** в браузере.
2. Войдите по номеру телефона (код придёт в Telegram).
3. Нажмите **API development tools**.
4. Заполните форму:
   - **App title**: `Haruka` (любое)
   - **Short name**: `haruka`
   - **Platform**: Desktop
5. Нажмите **Create application**.
6. Скопируйте **`api_id`** (число) и **`api_hash`** (длинная строка).

При первом запуске Haruka попросит эти значения (или откроет веб-страницу
настройки). Храните их в **секрете** — они привязаны к вашему аккаунту.

## 🧩 Управление модулями

- Отправьте боту `.help` — список команд.
- Установить модуль: ответьте на `.py`-файл командой `.loadmod` или
  `.dlmod <имя>` из репозитория.
- Удалить модуль: `.unloadmod <имя>`.

---

## ❓ Решение проблем

- **Python 3.10+ не найден** — установите его и перезапустите лаунчер.
- **Первый запуск долгий** — это разовая загрузка зависимостей; дальше
  старт быстрый.
- **Ошибки git** — задайте переменную окружения `HARUKA_NO_GIT=1`.
