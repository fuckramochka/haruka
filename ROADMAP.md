# Roadmap

## Near term

- Expand loader and dispatcher integration tests.
- Add extension manifests with engine/Python dependency checks.
- Build stable inline form, gallery and list primitives.
- Improve Hikka migration diagnostics.
- Add Russian/English UI localization.
- Add structured logging and redacted support bundles.

## Mid term

- QR/web onboarding as an optional isolated component.
- Signed extension metadata and trust policy.
- Topic-aware send/reply facade.
- Multiple accounts through one supervisor and isolated processes.
- Safe update preview and rollback command.

## Research

- Out-of-process extension workers with capability permissions.
- Declarative command schemas and automatic Control Center forms.
- Reproducible extension lockfiles.

Roadmap items are intentions, not promises. Security and contract stability take priority.
