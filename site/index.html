Get started

Quick install guide

One command sets up everything — dependencies, virtual environment and libraries — automatically on first run.

1

Install Python 3.10+

Make sure Python 3.10 or newer and git are available on your system.

2

Clone the repo

Download Haruka from GitHub into a folder.

3

Run the launcher

The first-run script installs everything and starts the bot.

4

Enter API keys

Paste your API ID and API HASH, log in — done!

🐧 Linux / macOS / FreeBSD / Termux / UserLAnd
git clone https://github.com/coddrago/Heroku Haruka
cd Haruka
chmod +x start.sh
./start.sh
🪟 Windows
git clone https://github.com/coddrago/Heroku Haruka
cd Haruka
start.bat   # or: powershell -ExecutionPolicy Bypass -File .\start.ps1
Telegram API

How to get API ID & API HASH

Haruka signs in through Telegram's official API, so you need your own personal keys. It takes about a minute.

  1. Open my.telegram.org in your browser.
  2. Log in with your phone number — a code arrives in Telegram.
  3. Click API development tools.
  4. Fill the form: title Haruka, platform Desktop.
  5. Press Create application.
  6. Copy your api_id and api_hash — keep them secret!
